# Alpha and Omega Advisors

Professional Accountants and Tax Advisors website with integrated **PDF Editor & CSV Converter**.

Built on the WebDevPro Ultra Max 5 Master Template (Vite + React + TypeScript + Tailwind).

## Features

- Full multi-page website (Home, About, Services, FAQ, Testimonials, Contact)
- **PDF Editor** (`/pdf-editor`)
  - Upload & view multi-page PDFs
  - Add text annotations
  - Download edited PDF
  - Convert PDF text to CSV
  - 100% client-side (privacy first)
- PWA support (installable, offline page)
- Floating interactive WhatsApp assistant
- Mobile bottom navigation
- Responsive design
- Ready for Vercel deployment

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000 (or the port Vite shows).

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Import the repo on [vercel.com](https://vercel.com)
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Deploy
